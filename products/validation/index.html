Data Validation

Check whether your data meets defined requirements.

Problem and relevance

Data validation is used when a dataset must meet explicit rules before it is trusted, consumed or transferred. The rules may cover required values, ranges, allowed values, uniqueness, type constraints or cross-field consistency.

Validation is different from reconciliation: it tests one dataset against requirements rather than comparing corresponding records across two datasets.

Product purpose

This product asks: does this data satisfy its rules?

Design note

  • Three records, one passing record and two failing records.
  • There are two rule failures, even though only two records fail.
  • Record-failure counts and rule-failure counts can differ when one record breaks multiple rules.

What this product would need to prove

  • Actual supported input format and rule syntax.
  • Concrete evaluation semantics for missing values, ranges and uniqueness.
  • Observed findings with record, rule and reason.
  • Verified automation or delivery integration if available.
